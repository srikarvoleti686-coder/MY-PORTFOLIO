## 🌟 Overview

This repository hosts my personal developer portfolio and interactive browser experiments, highlighting my technical journey across AI engineering, systems programming, and game development.

### 🏎️ Featured: F1 Sim & 2D Racing Game Engine (`jack.html`)
An interactive, high-frame-rate browser racing simulation featuring:
- **Paddock Authentication & UI**: Custom-styled Formula 1 aesthetic with Tailwind CSS and custom typography (`Racing Sans One`, `Roboto Mono`).
- **Real-Time Physics & Collision Detection**: Responsive controls, steering, and obstacle collision calculations.
- **Dynamic Cockpit HUD**: Speedometer, gear shifts, lap times, and telemetry.
- **Canvas Rendering Loop**: Smooth 60 FPS animation loop optimized for minimal frame drops.

### 📄 Main Portfolio (`bulit.html`)
- **About Section**: Background, engineering philosophy, and academic credentials.
- **Skills Matrix**: Core languages (C, Java, Python), web fundamentals, and system utilities.
- **Interactive Contact**: Form and direct communication channels.

## 🚀 How to Run Locally

1. Clone the repository:
   ```bash
   git clone https://github.com/srikarvoleti686-coder/MY-PORTFOLIO.git
   cd MY-PORTFOLIO
   ```
2. Open either file directly in any modern browser:
   - Double-click `bulit.html` for the portfolio homepage.
   - Double-click `jack.html` to jump directly into the F1 Sim racing experience.
